# 부안 닭축제 제안서 (그린 v5) — 이미지 요청서

## 사용법
`images/` 폴더에 아래 **파일명 그대로** 넣고 `node build.js` 재실행 → 자동 반영.
없으면 규격 안내가 적힌 초록 점선 박스(또는 육각 자리)가 들어갑니다.
※ 육각형 자리(표지·지역브랜드·계림·치킨벨트·시그니처·결론)는 가로세로 비슷한 컷이 좋습니다.

| `cover2.jpg` | 표지(육각·소) | 부안 닭요리 / 축제 현장 | 1200×1200px |

| `masil.jpg` | 3.1 사계절 | 부안마실축제 현장(2026.5 해뜰마루) | 1400×1000px · 부안군 |
