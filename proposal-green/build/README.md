# 부안 닭축제 제안서 — 그린 v5 (농생명수도 전북 정책발표 스타일)

농림축산식품부 「K-푸드 세계화의 전진기지, 농생명수도 전북」 정책 발표자료의
톤앤매너(그린 계열 · 정부 정책발표 구도)를 적용한 버전입니다. 총 31장.

## 실행
```bash
npm install pptxgenjs      # 최초 1회
node build.js              # 부안닭축제_제안서_그린v5.pptx 생성
```

## 폰트
`Noto Sans KR`(굵은 고딕). 미설치 시 `lib.js`의 `const F` 를 `'맑은 고딕'` 으로 변경.

## 구조 (총 31장)
```
lib.js     그린 디자인 시스템 (컬러/헤더/알약/칩/불릿/링/육각/배너)
part1.js   표지 · 목차 · 01장 (제안요약 ~ 지역브랜드)
part2.js   02장 닭의 역사 · 03장 사업계획
part3.js   04장 검증·리스크 · 05장 재원·추진 · 결론
build.js   진입점
images/    사진 폴더 (이미지_요청서.md 참고)
```

## 수정 지점
| 대상 | 위치 |
|---|---|
| 컬러(그린) | `lib.js` 의 `C` |
| 폰트 | `lib.js` 의 `F` |
| 러닝 헤더 문구 / CI | `lib.js` 의 `RUN` / `CI` |
| 슬라이드 내용 | `part1~3.js` |

## 디자인 요소 (참고 자료 반영)
- 그린 상단 바(라임+딥그린) · 번호 제목 + 그린 언더바 · 러닝 헤더 · 우상단 CI
- 딥그린 헤더 알약(pill) + 뱃지 칩 · 그린 라벨 칩 · 흰 박스 부양
- 원형 링 다이어그램(국정과제형) · 육각 사진 · 점선 화살표(⇢)
- 딥그린 하단 배너 + 주황 강조 키워드
