# 부안 닭축제 종합제안서 — 그린 v5

농림축산식품부 「농생명수도 전북」 정책 발표자료 스타일(그린 계열·정부 정책발표 구도)로
재구성한 버전입니다. 총 31장. (내용·데이터는 검증된 v4.1과 동일)

## 산출물
| 파일 | 용도 |
|---|---|
| `부안닭축제_제안서_그린v5.pptx` | 최종 제안서 (PowerPoint) |
| `부안닭축제_제안서_그린v5_미리보기.pdf` | 미리보기 (전 31장) |
| `build/` | pptxgenjs 소스 (컬러·폰트·내용 일괄 수정) |

## 재빌드
```bash
cd build && npm install && node build.js
```
사진은 `build/images/` 에 파일명 그대로 넣으면 자동 반영 (`build/이미지_요청서.md` 참고).
