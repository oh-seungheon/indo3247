# 부안 닭축제 종합제안서 (v4.1)

전북 치킨벨트를 완성하는 부안 닭축제 제안서입니다. 총 31장.

## 산출물
| 파일 | 용도 |
|---|---|
| `부안닭축제_제안서_v4.pptx` | 최종 제안서 (PowerPoint) |
| `부안닭축제_제안서_v4_미리보기.pdf` | 미리보기 (전 31장) |
| `build/` | pptxgenjs 소스 (컬러·폰트·내용 일괄 수정 가능) |

## 재빌드
```bash
cd build
npm install        # 최초 1회 (pptxgenjs)
node build.js      # 부안닭축제_제안서_v4.pptx 생성
```
사진은 `build/images/` 에 파일명 그대로 넣으면 자동 반영됩니다 (`build/이미지_요청서.md` 참고).

## v4.1 변경사항
`build/변경사항_v4.1.md` 참고 — 예산 계획·추진 체계 신설, 생활인구 데이터 개편, 팩트체크 정정, 텍스트 겹침 수정.
